# Upright bear reference and 3D interpretation

Observed references: recovered original sprite IDs **312–315** are the upright walking cycle; **316** is the thrown defeat pose; **379, 380, 381** show successively lower portions of the same bear (18, 11, 5 pixels high). Walking frames are 24–32 pixels wide and 24–30 pixels high. See `art/hd-v1/references/bears.png` (nearest-neighbour native reference sheet), `art/ai-upscale-v1/bear-original-native.png`, and `dist/assets/hd/manifest.json`. The painted HD sheet is a secondary visual interpretation, not native evidence.

The recovered art has two hind feet, dangling broad arms, brown fur, round ears, a cream/light-orange muzzle and chest, a black nose, prominent eyes/brows, and an open red mouth. The old quadruped mesh did not reproduce this silhouette.

Saved Ghidra evidence outside the game repository: `../analysis/ENEMIES-AND-GATES-AUDIT.md`; raw assembly/pseudocode `../analysis/assembly/game-supplemental/0x17896.asm`, `../analysis/pseudocode/raw/game-supplemental/0x17896.c` (buried/emerging/running/retreating controller), and `0x1796e` (ordinary patrol acceleration). The existing reconstruction mirrors these in `dist/js/engine.js`, cases 9 and 10. Type 9 patrol and type 10 emerging bear are distinct native spawn/controller variants. Do not make every patrol bear disappear into the ground. Type 10's original running timer decrements once every four game updates from 30, with segment markers controlling emergence/retreat completion.

`dist/vr/js/bear-model.js` creates a fully enclosed procedural mesh with two animated hind legs, separate swinging arms, ears, cheeks, brows, eyes, muzzle, tongue, teeth, pale chest and paws. Walking height is approximately **0.96 m**, matching 30 pixels at the VR conversion of 32 pixels/metre. Maximum walking reach in X is approximately 0.52 m from its local origin, with a 0.67 m depth across arms. It faces local +X. `bear.y` is the ground/feet elevation. Emergence translates the complete body down by `(1 - visibility) × 0.96 m` and clips all mesh materials against a shared world-space Y plane at `bear.y`; the renderer must enable `localClippingEnabled`. There is no squash scaling.

Inference/new VR art: depth, back, fur surface, exact limb shapes and continuous rig motion are authored interpretations because the source contains only projected 2D pixels. The original clip's four walk poses are reproduced as an upright alternating stride, not claimed to be a frame-exact animation. No DOS executable or emulator was run for this change. The saved prior native analysis and recovered art were reused; no new REA session was necessary. Controller timing belongs to the simulation, not this mesh animator.

The original procedural rig used 51 closed sphere components in eight material batches. That presentation has been replaced by [smooth sculpted surfaces, blended coat masks and an articulated gait](NATURAL-BEARS.md), while preserving the source behavior described above. The current production model uses nine geometry/material batches. Automated checks do not establish physical headset performance or an original DOS runtime comparison.
