# Music remaster preparation

The game contains12 original MOD modules. [Inventory](inventory.json) records hashes, patterns, nonempty instruments and stage assignments. Stages3–5 use PRES;6/A MONSTER;7/8/G GLACE;9 MYSTERY;B–D KOOL;E MINES;F FINAL. Other modules accompany menus, codes, map or completion; BOULA/CARTE/CODE are present but not selected by the current app's stage/title/tally routing.

The original browser player deliberately models the recovered four-voice mixer: original MOD PCM samples are reduced to unsigned six-bit values; the output rate is about8403.36Hz mono with integer pitch stepping and nearest output sampling. This is a runtime choice, not evidence that the MOD files themselves contain only six-bit or8.4kHz samples. Upsampling a mixed recording cannot recover the lost detail. A faithful higher-fidelity arrangement should start with the MOD patterns/instrument data, retain original note/event timing and loops, and use the recording as a reference rather than noise-removal speech processing.

Historical audit status (superseded by release1.4.0 and [the complete sampled arrangements](../music-remaster-v1/README.md)): there was no connected music-generation/editing tool in that audit session. Plugin discovery found Runway with music capability, but it is not installed/connected. No third-party music job was submitted, no generated soundtrack exists, and in-game music remains unchanged. That was the initial preparation state. The new melody-preserving soundtrack uses deterministic sample orchestration rather than a text-only AI cover.

`node scripts/prepare-music-audit.mjs` reproduces [a24-second PRES reference](input/PRES-original-reference.wav) entirely from the browser mixer. It uses linear resampling to44.1kHz mono PCM16 and20Hz DC removal for interchange. These operations do not add spectral detail or constitute an improvement. Original MODs remain immutable. No DOS executable/emulator was run.

Suggested first AI experiment: use PRES as reference and preserve its melody, bass pattern, harmony, tempo changes, phrase/order boundaries and playful prehistoric character. Upgrade instrument timbres and percussion gently; no vocals, added intro, reharmonization or added bars. Produce a24-second comparison before a full arrangement, then export a loopable48kHz stereo master and exact loop boundaries. Reject changed notes, missed accents, displaced transitions, audible loop seams or interference with game effects. Do not replace the current soundtrack until that comparison is reviewed. Future game integration should be an independent Original/Remastered music preference with lazy loading and original fallback; graphics preference should not silently change music.
